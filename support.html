Cawing NAM Support

Cawing NAM is a Neural Amp Modeler player for macOS (standalone app and Logic / GarageBand Audio Unit) and iOS (iPhone and iPad).

Contact

To contact the developer with improvement ideas or general questions, please email cawingcrows.music@gmail.com.

Quick troubleshooting

  • No sound (Mac): Click Engage, allow microphone access in System Settings → Privacy & Security → Microphone, and confirm the Audio tab input/output devices.
  • No sound (iOS): On the Stage tab, tap STANDBY to start the engine. Allow microphone access in Settings → Cawing NAM. Use a USB audio interface when possible.
  • Empty library: Import .nam files (Mac: File → Import NAM Profiles…; iOS: Library → + → Import). TONE3000 sign-in is optional.
  • Plugin missing in Logic (Mac): Launch Cawing NAM once from Applications, then rescan Audio Units in Logic.
  • High latency: Use an audio interface, buffer 64–128, and avoid Bluetooth I/O.

TONE3000

TONE3000 is an optional third-party catalog. Account, search, and download issues on that service are handled by TONE3000. Report a community capture on tone3000.com.
